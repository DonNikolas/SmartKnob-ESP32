# SmartKnob enclosure V3

## Files
- `SmartKnob-Assembly.f3z`: Fusion assembly with enclosure, motor and PCB.
- `Base Enclosure V3.step`: enclosure STEP export.
- `SmartKnob Enclosure Project.3mf`: Bambu Studio print project.
- `photos/`: photographs of the printed enclosure.

## Print configuration
- Housing: blue Bambu PLA-CF.
- LED diffuser: white eSUN PLA.
- Nozzle diameter: 0.4 mm.
- Layer height: 0.08 mm.
- Wall generator: Arachne.

## Results
The V3 enclosure was printed and visually assessed as satisfactory.
Switching to Arachne eliminated the missing paths in the diffuser
in the slicer preview.

Diffuser adhesion was an issue in earlier prints.
Long-term adhesion and mechanical durability remain to be verified.
